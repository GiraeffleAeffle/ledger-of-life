# Stadtstack Data

Standalone Node.js ≥22 city-data collector and read-only open-data/MCP publisher. No Next.js dependency and no resident location is collected or persisted. All outputs cover a **whole city**, including road corridors up to ~25 km outside its bounds; resident-home filtering must happen on the resident's device. The optional MCP spatial searches see the query **where the MCP runs**: on a local machine, it stays local; a hosted MCP operator would see the coordinates submitted to that host.

The **0.3.2 source checkpoint is not a deployable data release**. Tracked `out/` still contains the sealed 0.3.1 snapshot; no new source acquisition or model execution is implied by the package version. Fresh VM-only acquisition, admitted corrections, composed release validation and governed deployment require separate evidence before 0.3.2 can be served.

```sh
npm run collect -- "$IMPORT_PLAN" "$IMPORT_PLAN_SHA256"  # explicit offline import only
npm run knowledge:prepare -- --config "$INTAKE_PLAN" --config-sha256 "$INTAKE_PLAN_SHA256"
npm run publish -- --plan "$PUBLICATION_PLAN" --plan-sha256 "$PUBLICATION_PLAN_SHA256"
# Select the immutable governed candidate for checks; tracked out/ is not a serving root.
export STADTSTACK_MCP_RELEASE_DIR="$GOVERNED_RELEASE_DIR"
npm test
# Serve only after verification and the required release authorization.
npm run mcp                           # stdio
npm run mcp:http                      # Streamable HTTP http://127.0.0.1:4318/mcp
```

Current acquisition, source preparation, native inference and publication run only on the authoritative **codex-workstation VM**, with **OpenAI Codex only**. Mac/Haiku execution, hosted Jev/TypeSafe evaluation and the former `evaluate`, `evaluate:core`, `weekend` and implicit `all` chains are retired. Historical model/experiment receipts remain historical evidence; they are neither a current execution path nor a claim that another provider ran again.
The ignored `cache/` contains explicitly governed source bytes, prepared text, model responses, task results and private artifacts. No generic last-good HTTP fallback, mirror retry, raw CCF checkout import or unscoped geocoding remains. Pure feed/geodata/OSM/Atlas parsers and static validators remain available for already-authorized inputs. Existing city facts, including CCF-derived facts, enter the acquisition lane only through an authenticated retained-publication import with their original provenance and clocks; no new HTTP observation is invented.

`collect` requires a pinned import plan and never fetches. Sealed publication members authenticate the original manifest identity and exact member bytes. Private pre-cleanup Git snapshots use a separate authenticated commit/tree/blob proof solely for historical change reconstruction; only identifiers, versions and source hashes reach change feeds.
